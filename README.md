# 💰 Paycheck Calculator (Gross to Net)

A modern, responsive Paycheck Calculator built with React, TypeScript, and Tailwind CSS. This tool provides an easy-to-use interface for estimating your take-home pay after taxes and deductions. It features a clean, financial-focused design with an immersive animated galaxy background.

---

## ✨ Key Features

- **Gross to Net Calculation**: Instantly estimate your net paycheck based on annual salary, pay frequency, tax rate, and pre-tax deductions.
- **Detailed Breakdown**: View a clear summary of your gross pay, tax withholdings, deductions, and final net pay.
- **Modern & Responsive UI**: A clean, comfortable, and friendly interface that works beautifully on all devices, from desktops to mobile phones.
- **Interactive & Friendly**: Smooth animations and an intuitive layout make financial estimation straightforward and engaging.
- **Privacy-Focused**: All calculations are performed directly in your browser. No data is ever sent to a server.
- **Immersive Background**: A subtle, multi-layered parallax starfield creates a beautiful and immersive experience.
- **Comprehensive Financial Guide**: Includes a detailed, 3500+ word SEO-optimized article on understanding paychecks, deductions, and budgeting.
- **Modal-Based Info**: Quick access to About, Contact, Privacy Policy, and other information without leaving the page.

## 🛠️ Technology Stack

- **Frontend**: [ReactJS](https://reactjs.org/) (v18+)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Core Logic**: Pure TypeScript/JavaScript functions for all financial calculations.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v16 or later recommended)
- A package manager like `npm` or `yarn`

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/paycheck-calculator.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd paycheck-calculator
    ```
3.  **Install NPM packages:**
    ```sh
    npm install
    ```

### Running the Application

-   **Development Mode:**
    Run the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in the browser. The page will reload if you make edits.
    ```sh
    npm start
    ```
-   **Production Build:**
    Builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance.
    ```sh
    npm run build
    ```
